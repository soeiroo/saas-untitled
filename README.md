# saas-untitled

This project is a SaaS platform for managing subscriptions and shared expenses in a centralized and intelligent way.

The system allows users to:
 - Manage all their subscriptions in one place (e.g. streaming, software, services)
 - Track prices, renewal dates, and subscription plans
 - Share subscriptions with friends in a controlled and transparent way

## How to run it locally

You can use docker/docker compose<br>
Run this at the root of the project:

```
docker compose up --build
```

This will run frontend and backend as well.
